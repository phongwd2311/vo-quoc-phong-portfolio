# Portfolio project brief

## Goal

Implement a professional, responsive portfolio website based on:

- factual content from the CV PDF;
- visual design from Figma;
- the current static HTML/CSS/JavaScript project.

## Current stack

- HTML
- CSS
- JavaScript
- Static assets

Do not migrate to React, Next.js, Vue, Astro, or another framework unless explicitly approved.

## Required outputs

- Responsive desktop, tablet, and mobile UI.
- Accurate personal and professional information.
- Downloadable CV PDF.
- Working navigation and interactions.
- Accessible markup and keyboard states.
- No console errors, missing files, or horizontal overflow.
- Repository ready for GitHub and Vercel after approval.

## Default viewport checks

- Desktop: 1440 × 900
- Laptop: 1280 × 800
- Tablet: 768 × 1024
- Mobile: 390 × 844

These are verification targets, not fixed CSS canvas sizes.

## Non-goals

- Do not invent portfolio content.
- Do not alter the source PDF.
- Do not push or deploy automatically.
- Do not add unnecessary dependencies.
